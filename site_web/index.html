Envoyer le programme au mBot1

      

        
    
          
  1. Fermez mBlock et l'IDE Arduino s'ils sont ouverts (un seul logiciel à la fois peut utiliser le câble).
    2. 
          
  2. Branchez la carte mCore à l'ordinateur avec le câble USB et allumez le mBot1.
    3. 
          
  3. Cliquez sur « Compiler et envoyer », puis choisissez le port USB-SERIAL CH340 dans la fenêtre du navigateur.
    4. 
        

        
        

        

        
Le programme est compilé sur cet ordinateur (serveur local), puis enregistré dans la carte : il démarre aussitôt et
          reste en mémoire après l'arrêt du robot. Il remplace le microprogramme du mode direct ; le bouton ci-dessous le réinstalle.
